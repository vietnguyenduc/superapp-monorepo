# Skills Usage Guide

This document organizes and summarizes the currently installed agent skills located in `@[superapp-monorepo/.agent/skills]`, categorized by the bundles they originated from. Use this to determine when and how an AI assistant should leverage these tailored contexts.

## 🌐 The "Web Wizard" Pack
_For building modern, high-performance web apps._

*   **`frontend-design`**: Use when building or reviewing frontend aesthetics. Enforces a designer-engineer mindset over plain layout generation.
*   **`react-best-practices`**: Use when writing new React components or Next.js pages. A comprehensive Vercel-maintained performance optimization and data fetching guide.
*   **`react-patterns`**: Use when architecting client-side functionality. Focuses on modern React patterns, hooks, and clean composition principles.
*   **`nextjs-best-practices`**: Use for Next.js App Router tasks, including Server Components, advanced data fetching, and routing patterns.
*   **`tailwind-patterns`**: Use when styling applications with Tailwind CSS. Incorporates Tailwind v4 principles, CSS-first configurations, container queries, and design tokens.
*   **`form-cro`**: Use to optimize non-registration forms (like lead captures, contact, surveys, applications, and checkouts) for conversion rates.
*   **`seo-audit`**: Use when diagnosing, analyzing, and auditing technical or structural SEO issues affecting crawlability, indexation, and rankings.

## 🖌️ The "Web Designer" Pack
_For beautiful, pixel-perfect, and dynamic user experiences._

*   **`ui-ux-pro-max`**: A comprehensive masterclass design guide. Use when designing new UI components, choosing palettes, typography, or performing overarching UX reviews.
*   **`3d-web-experience`**: Use when incorporating 3D visuals (like Three.js/React-Three-Fiber). Helps balance visual wonder with performance and accessibility.
*   **`canvas-design`**: Use for creating aesthetic design philosophies to be expressed visually as PDFs, Markdown, or images.
*   **`mobile-design`**: Use to enforce mobile-first, touch-first, and platform-respectful UI design constraints.
*   **`scroll-experience`**: Use when building cinematic, scroll-driven journeys. Controls pacing, micro-animations, and visual impact on the scroll axis.

## ⚡ The "Full-Stack Developer" Pack
_For end-to-end applications and robust backend architecture._

*   **`senior-fullstack`**: The complete end-to-end toolkit leveraging modern tools and rigorous best practices for the entire stack.
*   **`frontend-developer`**: Use for building React 19 / Next 15 applications with complex responsive layouts and client-side web architectures.
*   **`backend-dev-guidelines`**: Use when working with the backend layer (routes, controllers, services, repositories, database models, etc.). Enforces production-grade architectural and reliability constraints.
*   **`api-patterns`**: Use when designing API contracts. Helps resolve REST vs. GraphQL vs. tRPC selection, and enforces standards on versioning, pagination, and data structures.
*   **`database-design`**: Use when making primary database architecture decisions (e.g., schema structures, relationship modeling, indexing, and ORM choices).
*   **`stripe-integration`**: Use to map out, structure, and implement PCI-compliant checks, subscriptions, webhooks, and billing flows.

## 🛠️ Other Installed Utilities

*   **`webapp-testing`**: A Playwright-powered toolkit. Use when interacting with or testing local web apps, capturing browser screenshots, verifying client flows, or reviewing browser logs.
