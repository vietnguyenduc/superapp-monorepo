# Agent Memory & Task Tracking

This folder is used by Antigravity to store persistent state, implementation plans, and artifacts generated during multi-agent workflows.

## Recommended Workflow

1. **Product Manager Phase**: Output a `product_spec.md` here.
2. **Architecture Phase**: Output an `architecture_design.md` here.
3. **Planning Phase**: Output an `implementation_plan.md` here.
4. **Execution Phase**: The Builder agent will check off tasks in the `implementation_plan.md` as they are completed.
