Superapp New App Generator

Generates a Vite app skeleton matching the Superapp monorepo conventions (React 18 + TypeScript 5.8, Supabase, shared IAM, docs set).

After generating

  1. Unzip into the monorepo root so the apps/<app> folder is created.
  2. Run npx turbo run check-types lint test build --filter=<app>.
  3. Add the app to root README.md, AGENTS.md, turbo.json, and .github/workflows/deploy-changed-apps.yml.
  4. Link a Vercel project and push origin/viet for preview.
