👤 User Creation Steps

  2. Login to your application
  3. Open browser console (F12)
  4. Run: window.supabase.auth.getUser().then(user => console.log(user.id))
  5. Copy the user ID value
  6. Replace USER_ID_FROM_AUTH in the SQL above
  7. Execute the INSERT statement
