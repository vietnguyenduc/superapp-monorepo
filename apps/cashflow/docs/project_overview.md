# Cashflow App - Project Overview

## Project Vision
Xây dựng ứng dụng quản lý công nợ hiện đại, AI-native, với khả năng tự động hóa và tối ưu hóa quy trình thu chi cho doanh nghiệp SME.

## Core Features
- Quản lý khách hàng và công nợ
- Import/Export giao dịch hàng loạt
- Dashboard real-time analytics
- Role-based access control
- Multi-branch management
- AI-powered insights

## Technology Stack
- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** Supabase (PostgreSQL + Auth + Storage)
- **Deployment:** Vercel + Supabase Edge Functions
- **AI/ML:** OpenAI API + Custom Agents

## Architecture Pattern
AI-Native Development với multi-agent orchestration:
- Orchestrator điều phối toàn bộ workflow
- Specialized agents cho từng domain
- Memory-driven development
- Continuous learning and adaptation

## Development Philosophy
- AI-first approach
- Domain-driven design
- Test-driven development
- Continuous integration/deployment
- Knowledge accumulation
