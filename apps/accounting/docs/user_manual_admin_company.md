## 1. Giới thiệu

Cashflow là hệ thống quản lý dòng tiền giúp bạn theo dõi, quản lý và báo cáo các giao dịch tài chính của công ty. Với vai trò Admin Company, bạn có toàn quyền quản lý:

- Tất cả khách hàng trong công ty
- Tất cả giao dịch
- Tất cả chi nhánh
- Nhân viên và phân quyền
- Cài đặt hệ thống

### Tính năng chính

- ✅ Quản lý khách hàng đa chi nhánh
- ✅ Theo dõi giao dịch theo thời gian thực
- ✅ Báo cáo tài chính chi tiết
- ✅ Nhập dữ liệu hàng loạt
- ✅ Quản lý quyền truy cập nhân viên
- ✅ Cài đặt tùy chỉnh linh hoạt

## 3. Dashboard - Tổng quan

Dashboard cung cấp cái nhìn tổng quan về tình hình tài chính của công ty.

### 3.1 Các chỉ số chính

- **Tổng số khách hàng**: Số lượng khách hàng đang hoạt động
- **Tổng số giao dịch**: Số lượng giao dịch trong khoảng thời gian
- **Tổng dư nợ**: Tổng số tiền khách hàng nợ
- **Tổng thu**: Tổng số tiền thu trong kỳ
- **Tổng chi**: Tổng số tiền chi trong kỳ

### 3.2 Biểu đồ

- **Biểu đồ dòng tiền**: Hiển thị xu hướng thu chi theo thời gian
- **Biểu đồ dư nợ theo ngân hàng**: Phân bổ dư nợ theo từng tài khoản ngân hàng
- **Biểu đồ phân loại giao dịch**: Tỷ lệ các loại giao dịch (thu, chi, điều chỉnh)

### 3.3 Khách hàng có dư nợ cao nhất

Danh sách 10 khách hàng có dư nợ cao nhất để ưu tiên thu hồi.

### 3.4 Giao dịch gần đây

Danh sách 10 giao dịch gần nhất để theo dõi hoạt động.

## 4. Quản lý Khách hàng

### 4.1 Xem danh sách khách hàng

1. Chọn menu "Khách hàng" từ sidebar
2. Xem danh sách tất cả khách hàng
3. Sử dụng bộ lọc để tìm kiếm:
   - Tìm kiếm theo tên, mã, điện thoại
   - Lọc theo chi nhánh
   - Lọc theo trạng thái (có dư nợ, không dư nợ)

### 4.2 Thêm khách hàng mới

1. Nhấn nút "Thêm khách hàng"
2. Điền thông tin:
   - **Mã khách hàng**: Mã duy nhất (bắt buộc)
   - **Họ và tên**: Tên đầy đủ (bắt buộc)
   - **Số điện thoại**: Để liên hệ (bắt buộc)
   - **Email**: Để liên hệ
   - **Địa chỉ**: Địa chỉ khách hàng
   - **Chi nhánh**: Chọn chi nhánh quản lý
   - **Dư nợ đầu kỳ**: Số tiền nợ ban đầu
3. Nhấn "Lưu"

### 4.3 Chỉnh sửa thông tin khách hàng

1. Nhấn vào khách hàng muốn chỉnh sửa
2. Thay đổi thông tin cần thiết
3. Nhấn "Cập nhật"

### 4.4 Xóa khách hàng

⚠️ **Lưu ý**: Chỉ xóa khách hàng khi không còn giao dịch liên quan.

1. Nhấn vào khách hàng muốn xóa
2. Nhấn nút "Xóa"
3. Xác nhận xóa

### 4.5 Xem chi tiết khách hàng

1. Nhấn vào khách hàng
2. Xem thông tin chi tiết:
   - Thông tin cá nhân
   - Lịch sử giao dịch
   - Dư nợ hiện tại
   - Biểu đồ dư nợ theo thời gian

   - **Loại giao dịch tùy chỉnh**: (nếu có cấu hình)

### 5.3 Chỉnh sửa giao dịch

2. Nhấn nút "Xóa"

## 6. Nhập dữ liệu

### 6.1 Nhập khách hàng hàng loạt

1. Chọn menu "Nhập dữ liệu" → "Nhập khách hàng"
2. Tải xuống template Excel
3. Điền thông tin khách hàng vào template
4. Upload file đã điền
5. Xem preview dữ liệu
6. Nhấn "Nhập dữ liệu"

**Định dạng file Excel:**
- Column A: Mã khách hàng (bắt buộc)
- Column B: Họ và tên (bắt buộc)
- Column C: Số điện thoại (bắt buộc)
- Column D: Email
- Column E: Địa chỉ
- Column F: Chi nhánh
- Column G: Dư nợ đầu kỳ

### 6.2 Nhập giao dịch hàng loạt

1. Chọn menu "Nhập dữ liệu" → "Nhập giao dịch"
2. Tải xuống template Excel
3. Điền thông tin giao dịch vào template
4. Upload file đã điền
5. Xem preview dữ liệu
6. Nhấn "Nhập dữ liệu"

**Định dạng file Excel:**
- Column A: Mã khách hàng (bắt buộc)
- Column B: Loại giao dịch (bắt buộc)
- Column C: Số tiền (bắt buộc)
- Column D: Ngày giao dịch
- Column E: Mô tả

### 6.3 Xử lý lỗi nhập

Nếu có lỗi nhập:
- Hệ thống sẽ hiển thị danh sách lỗi
- Kiểm tra và sửa lỗi trong file Excel
- Upload lại file đã sửa

## 8. Cài đặt

1. Chọn menu "Cài đặt" → "Tài khoản ngân hàng"
2. Xem danh sách tài khoản

   - Tên chủ tài khoản
   - Chi nhánh ngân hàng

### 8.2 Quản lý chi nhánh

1. Chọn menu "Cài đặt" → "Chi nhánh"
2. Xem danh sách chi nhánh
3. Thêm chi nhánh mới:
   - Tên chi nhánh
   - Địa chỉ
   - Số điện thoại
   - Người quản lý
4. Chỉnh sửa hoặc xóa chi nhánh

### 8.3 Quản lý loại giao dịch

1. Chọn menu "Cài đặt" → "Loại giao dịch"
2. Xem danh sách loại giao dịch
3. Thêm loại giao dịch mới:
   - Tên loại
   - Màu sắc hiển thị
   - Hệ số tính toán (thu/chi)
   - Loại tác động (tăng/giảm dư nợ)
4. Chỉnh sửa hoặc xóa loại giao dịch

### 8.4 Cài đặt màu sắc

1. Chọn menu "Cài đặt" → "Màu sắc"
2. Tùy chỉnh màu sắc cho:
   - Giao dịch thu
   - Giao dịch chi
   - Dư nợ cao
   - Dư nợ thấp

### 8.5 Nhập dư nợ đầu kỳ

1. Chọn menu "Cài đặt" → "Nhập dư nợ đầu kỳ"
2. Tải xuống template Excel
3. Điền dư nợ đầu kỳ cho từng khách hàng
4. Upload file
5. Nhấn "Nhập dữ liệu"

⚠️ **CẢNH BÁO**: Hành động này sẽ xóa tất cả dữ liệu. Không thể hoàn tác.

1. Chọn menu "Cài đặt" → "Reset dữ liệu"
2. Nhấn "Bắt đầu reset"
3. Xác nhận reset

## 11. Sao lưu và Khôi phục dữ liệu

⚠️ **QUAN TRỌNG**: Chỉ Admin Master hoặc Admin System được cấp quyền mới thực hiện các thao tác backup/restore.

### 11.1 Tổng quan về Backup/Restore

Sao lưu và khôi phục dữ liệu là các quy trình quan trọng để bảo vệ dữ liệu của công ty khỏi:
- Lỗi hệ thống
- Xóa nhầm dữ liệu
- Tấn công mạng
- Thất bại phần cứng

### 11.2 Backup Database

#### 11.2.1 Backup qua Supabase Dashboard (Khuyên dùng)

1. Truy cập https://supabase.com/dashboard
2. Chọn project: `peslmsctejmvkwzyohke`
3. Điều hướng đến: Database → Backups
4. Nhấn nút "Create backup" hoặc "New backup"
5. Đặt tên cho backup (ví dụ: `backup-2026-04-27-pre-deployment`)
6. Chọn thời điểm backup (ngay bây giờ hoặc lịch trình)
7. Nhấn "Confirm" để tạo backup
8. Kiểm tra backup hiển thị trong danh sách với trạng thái "Completed"

#### 11.2.2 Backup tự động

**Cấu hình trong Supabase Dashboard:**
1. Supabase Dashboard → Project Settings → Database
2. Tìm section "Automated backups"
3. Enable "Automated backups"
4. Chọn tần suất backup (khuyến nghị: Daily)
5. Chọn thời gian backup (khuyến nghị: 2:00 AM - 4:00 AM giờ địa phương)
6. Chọn retention period (khuyến nghị: 7-30 ngày)
7. Nhấn "Save"

### 11.3 Restore Database

#### 11.3.1 Restore qua Supabase Dashboard (Khuyên dùng)

1. Supabase Dashboard → Database → Backups
2. Chọn backup muốn restore
3. Nhấn "Restore" trên backup đã chọn
4. Xác nhận restore (sẽ ghi đè data hiện tại)
5. Đợi restore hoàn thành
6. Kiểm tra data sau restore
7. Test các chức năng chính
8. Verify RLS policies

⚠️ **CẢNH BÁO**: Restore sẽ ghi đè toàn bộ dữ liệu hiện tại. Hãy backup database hiện tại trước khi restore.

### 11.4 Best Practices

#### Trước khi Backup
- ✅ Kiểm tra database health
- ✅ Đảm bảo không có active transactions quan trọng
- ✅ Thông báo cho users về scheduled maintenance
- ✅ Test backup process trong staging environment

#### Sau khi Backup
- ✅ Verify backup integrity
- ✅ Test restore process (thử restore trong staging)
- ✅ Lưu backup metadata (date, size, description)
- ✅ Cập nhật backup log

#### Trước khi Restore
- ✅ Backup database hiện tại (trước khi restore)
- ✅ Thông báo cho users về downtime
- ✅ Lưu schema version hiện tại
- ✅ Kiểm tra compatibility giữa backup và current schema

#### Sau khi Restore
- ✅ Test tất cả chức năng chính
- ✅ Verify data consistency
- ✅ Kiểm tra foreign key constraints
- ✅ Thông báo cho users về system availability

### 11.5 Troubleshooting

#### Backup thất bại
- Kiểm tra network connection
- Verify database credentials
- Kiểm tra disk space trên server
- Thử backup nhỏ hơn (table cụ thể)

#### Restore thất bại
- Kiểm tra schema version
- Drop và recreate constraints
- Verify user permissions
- Sử dụng `--clean` flag với pg_dump

### 11.6 Tài liệu chi tiết

Để xem hướng dẫn chi tiết hơn về backup và restore, tham khảo tài liệu kỹ thuật:
- **File:** `memory/backup_restore_procedures.md`
- **Nội dung:** Hướng dẫn đầy đủ qua CLI, psql, troubleshooting, emergency procedures

## 12. Câu hỏi thường gặp

### Q1: Tôi quên mật khẩu thì làm sao?

**A:** Nhấn "Quên mật khẩu" ở trang đăng nhập, nhập email, và làm theo hướng dẫn để reset mật khẩu.

### Q2: Làm sao để thêm nhân viên mới?

**A:** Vào Cài đặt → Nhân viên → Thêm nhân viên, điền thông tin và chọn vai trò.

### Q3: Tôi có thể xem dữ liệu của chi nhánh khác không?

**A:** Với vai trò Admin Company, bạn có thể xem và quản lý dữ liệu của tất cả chi nhánh trong công ty.

### Q4: Làm sao để xuất báo cáo?

**A:** Vào menu Báo cáo, chọn loại báo cáo, khoảng thời gian, bộ lọc, sau đó nhấn "Xuất".

### Q5: File nhập dữ liệu bị lỗi thì sao?

**A:** Kiểm tra định dạng file, đảm bảo đúng template, kiểm tra các trường bắt buộc đã điền, và upload lại.

### Q6: Tôi có thể xóa giao dịch đã nhập không?

**A:** Có, nhưng xóa giao dịch sẽ ảnh hưởng đến dư nợ khách hàng. Hãy cân nhắc kỹ trước khi xóa.

### Q7: Làm sao để backup dữ liệu?

**A:** Vào Supabase Dashboard → Database → Backups → Nhấn "Create backup". Xem chi tiết ở phần [Sao lưu và Khôi phục dữ liệu](#11-sao-lưu-và-khôi-phục-dữ-liệu).

### Q8: Tôi có thể tùy chỉnh loại giao dịch không?

**A:** Có, vào Cài đặt → Loại giao dịch để thêm, chỉnh sửa hoặc xóa loại giao dịch tùy chỉnh.
