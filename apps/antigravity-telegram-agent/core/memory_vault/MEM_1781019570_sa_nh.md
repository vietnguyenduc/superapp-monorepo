# Task Objective
The primary objective was to implement responsive design fixes for two specific pages: `AssetsPage` and `DocumentsPage`. The goal was to ensure optimal display and user experience across both desktop (≥640px) and mobile (<640px) screen sizes.

# Strategy Used
For both pages, the strategy involved maintaining the existing table layouts for desktop views while introducing new card-based layouts for mobile views.

-   **AssetsPage**:
    -   **Desktop (≥640px)**: Retained the existing 3-column table structure.
    -   **Mobile (<640px)**: Transitioned to a card layout where each item is presented as an individual card. Information within each card was organized into a 2-column grid, with a status badge positioned on the right.
-   **DocumentsPage**:
    -   **Desktop (≥640px)**: Retained the existing 4-column table structure.
    -   **Mobile (<640px)**: Implemented a card layout where the title and a badge were placed at the top, and the date along with a download button were positioned below.

Verification of the changes was performed by running the development server and utilizing browser DevTools to simulate mobile environments, specifically testing with iPhone SE and Galaxy S8 viewports.
