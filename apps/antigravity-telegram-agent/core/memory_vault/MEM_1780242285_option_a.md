# Task Objective
The primary objective was to refactor the mobile bottom navigation of the `Operations Portal` application. This involved aligning its design and functionality with the `Inventory Operation`'s global standard, specifically by reducing the number of primary bottom navigation items to four, introducing an "Add" button that opens a `MobileMenuDrawer`, and utilizing standard UI components.

# Strategy Used
The strategy involved modifying the `src/App.tsx` file to implement the new navigation structure. Key steps included:
1.  Replacing the existing custom `MobileBottomNav` implementation with a standard component from the `@superapp/ui` library.
2.  Restructuring the bottom navigation to display only four main items (`Tổng quan`, `Check-in`, `Sự cố`, `Tài sản`).
3.  Adding a fifth "Thêm" (Add) button that, when tapped, triggers a `MobileMenuDrawer` (bottom sheet) to display the remaining navigation items (`Đào tạo`, `Tài liệu`, `Chat`, `Khẩn cấp`, `Hướng dẫn`).
4.  Ensuring the existing hamburger menu functionality for the sidebar drawer remained unchanged.
