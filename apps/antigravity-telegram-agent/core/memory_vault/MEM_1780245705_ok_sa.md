# Task Objective
The objective was to fix the "message is too long" error encountered in the Telegram bot, specifically when sending responses that exceed Telegram's message length limit (4096 characters).

# Strategy Used
The strategy involved implementing a `safe_send` function to handle message sending. This function automatically splits long messages into multiple parts and sends them sequentially, preventing the "message is too long" error. The existing direct message sending calls (`bot.send_message` and `bot.reply_to`) were replaced with calls to this new `safe_send` function.
