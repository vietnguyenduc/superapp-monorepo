# Task Objective
The primary objective was to resolve several identified UI/UX issues across the application to improve user experience and visual consistency. Specific issues included:
1.  Preventing the Floating Action Button (FAB) from overlapping the BottomTabBar.
2.  Decluttering the application header.
3.  Optimizing the layout and text of "Tạo PO + Tìm + Lọc" (Create PO + Search + Filter) buttons for mobile responsiveness.
4.  Standardizing the sidebar width to ensure consistency with the overall layout.

# Strategy Used
The strategy involved a targeted approach to each UI/UX issue. For each problem, the relevant component file was identified, and specific CSS/Tailwind utility class adjustments were applied to address the layout, positioning, or visibility concerns. This included modifying positioning classes, removing redundant elements, and adjusting width properties to achieve the desired responsive behavior and visual harmony.

# Code Snippets (Skills)
-   **`QuickAddMenu.tsx`**: Modified FAB positioning from `bottom-6` to `bottom-20 lg:bottom-6` to prevent overlap with the BottomTabBar on smaller screens.
-   **`Navigation.tsx`**: Removed a redundant `div.hidden.lg:block` element that displayed user name and role next to the avatar, decluttering the header.
-   **`InventoryMRPPage.tsx`**: Implemented layout adjustments for the "Tạo PO + Tìm + Lọc" buttons, including making the search bar full-width on mobile, wrapping filter and PO buttons to a new line, and shortening button text for mobile displays.
-   **`Sidebar.tsx`**: Adjusted sidebar width classes from `w-72 lg:w-80` to `w-60 lg:w-64 xl:w-72` to ensure consistent sizing across different screen resolutions and match the main layout.
