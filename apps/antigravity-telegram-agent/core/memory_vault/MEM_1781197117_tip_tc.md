# Lessons Learned
- **Succeeded:**
    - Both applications share a nearly identical structure, including `BaseService.execute()` pattern, `FallbackService` singleton, `setupTests.ts` with mock Supabase, and common dependencies. This consistency simplifies the approach to testing.
    - The existing setup already includes robust mocks for Supabase, `matchMedia`, and `ResizeObserver`, along with a fallback mechanism, which will significantly ease the process of writing new tests.
- **Challenges Identified (for future test implementation):**
    - The `FallbackService` relies on `localStorage`, which will require careful mocking in tests.
    - `BaseService` directly accesses `localStorage.getItem('isTrial')`, also necessitating mocking.
    - The widespread use of `lazy()` for components means that tests for these components will need to be wrapped in a `Suspense` component.
