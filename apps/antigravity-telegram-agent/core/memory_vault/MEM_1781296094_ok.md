# Task Objective
To analyze and create a detailed fix plan for 9 failed files and 46 failed tests within the Cashflow App, aiming to resolve the identified issues and ensure test suite passes.

# Strategy Used
The strategy involved a systematic analysis of the failed tests to identify root causes. This included:
1.  Reviewing specific test failures in files like `dataCleaning.test.ts`, `rbac.test.ts`, `importUtils.test.ts`, `errorHandling.test.tsx`, `transactionTypeNames.test.tsx`, `BalanceByBankChart.test.tsx`, `formatting.test.ts`, `backupRecovery.test.ts`, and `dashboardMetrics.test.ts`.
2.  Pinpointing the exact reason for failure, such as incorrect assertion syntax (`vi.expect` vs `expect`), mismatched expectations with source code logic, incorrect data keys (`customer_name` vs `customer_code`), missing error codes, missing mocks (`useAuthContext`), or formatting discrepancies.
3.  Developing a specific, actionable fix for each identified root cause.
